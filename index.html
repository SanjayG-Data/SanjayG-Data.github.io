OPEN SOURCE · MITPersonal project

ExaDoctor

Read-only diagnostics CLI for Exasol. Scans a database for repeated SQL errors, slow or memory-heavy statements, swap activity, unusual storage growth and long-lived sessions, and reports every finding with the evidence behind it. If the data needed for a check isn't available, it says so instead of guessing. Includes per-statement deep dives, baseline snapshots for tracking change over time, and an optional plain-language summary from a local LLM.

$ exadoctor scan --explain  →  findings + evidence + local LLM summary  ·  no writes, no black box
